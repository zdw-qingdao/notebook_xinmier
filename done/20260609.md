Docker 镜像导出和导入：

导出镜像（当前电脑）：

# 查看本地镜像
docker images

# 导出为 tar 文件
docker save -o myimage.tar 镜像名:tag

# 例如
docker save -o sound_detect.tar sound_detect:latest
导入镜像（另一台电脑）：

# 把 tar 文件拷贝过去后
5

# 验证
docker images
如果要导出的是正在运行的容器（包含运行时修改），用 docker export / docker import：

# 导出容器
docker export 容器ID -o container.tar

# 导入为镜像
docker import container.tar 新镜像名:tag
区别：save/load 保留完整的层和元数据（推荐），export/import 会压平为单层且丢失 CMD/ENTRYPOINT 等配置。
