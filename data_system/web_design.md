# Foundry 前端页面设计


## 整体布局

```
┌──────────────────────────────────────────────────────┐
│  Foundry                    [用户名]                  │  顶栏
├────────┬─────────────────────────────────────────────┤
│        │                                             │
│ 数据    │                   已完成项目：                │
│ 数据集  │                   进行中项目：                │
│ 代码    │                   数据总量：                 │
│ 模型结果 │                   .....                    │
│ 训练    │                                             │
│ 评测    │                                             │
└────────┴─────────────────────────────────────────────┘
  侧边栏                   内容区
```
侧边栏导航：数据采集 / 数据集 / 代码 / 模型 / 训练 / 评测

- 标注版本多选：勾选多个版本时，用不同颜色区分
- 显示模式切换：
  - 叠加模式：每页批量显示 n 张图片，多个标注结果叠加在同一张图上，用颜色区分版本
  - 并列模式：针对单张图片，将所有已选标注版本并排显示，方便逐版本对比
- 交互方式：
  - 左键点击图片：放大查看
  - 右键点击图片：切换到并列模式，显示该图片的各标注版本
- 每页显示数量：可自定义（如 4 / 8 / 16 / 32），批量浏览
- 底部翻页：上一页/下一页，显示当前范围和总数

## 7. 页面流程总览

```
项目列表 → 采集批次列表 → 采集详情 → 标注查看
                                  ↓
                            新建标注（选择自动/手动）

数据集列表 → 新建数据集（选择采集+标注版本+范围）

代码配置列表 → 新建配置（填写仓库+参数）

训练任务列表 → 新建训练（选择数据集 → 选择代码配置 → 填写训练参数 → 开始训练）

模型列表 → 模型详情（查看训练结果/下载权重）

评测对比 → 选择多个模型 → 指标对比 + Val 图片对比（支持过滤）
```
