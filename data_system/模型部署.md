  参考onnx来进行的处理；不拆的话量化效果比较差；750还需要单独拆sigmod；
  整理这个逻辑；


def _detect_forward(self: Detect, x: list[torch.Tensor]):
    if not self.export:
        return _ORIGINAL_DETECT_FORWARD(self, x)
    outputs = []
    for index in range(self.nl):
        outputs.append(self.cv2[index](x[index]))
        classes = torch.sigmoid(self.cv3[index](x[index]))
        outputs.append(classes)
        outputs.append(torch.clamp(classes.sum(1, keepdim=True), 0, 1))
    return outputs

根据onnx文件，获取原来的模型结构；
原来的forward head是6维合到一起的，在进行量化的时候会导致精度下降；
这里的操作是将forward head的6维拆开了，拆开之后量化的时候会分别进行，量化后精度不会导致下降；
拆开之后，在相机侧推理的结果也是拆开的，需要对应的获取输出变量；
这里面加了sigmod函数，如果不加的话，需要在相机侧对应的加上；


将输出头去掉，直接获取feature输出，并将6路分开；
  1，输出头的某些计算在rknn上不支持，需要在相机上另外写；
  2，将6路分开的方式，对量化精度有提升；这种操作方式也来自官方测试：
    https://github.com/airockchip/rknn_model_zoo/blob/main/examples/yolov8/README.md
